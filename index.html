03 / THE IDEA

A different way to
read a pattern.

Each mock value moves the visual and the tone together. The simple mapping is 220 + 440 × value Hz: a value of 0 becomes 220 Hz, while 1 becomes 660 Hz. This is an illustrative rule, not a scientific sonification.
